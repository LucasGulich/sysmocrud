# SysmoCrud — Backend

API REST de gerenciamento de tarefas em Java 21 + Quarkus.

Consulte o [README principal](../README.md) para pré-requisitos e instruções completas.

## Comandos

```bash
./mvnw quarkus:dev        # modo desenvolvimento com recarga automática (porta 8080)
./mvnw test               # testes
./mvnw clean package      # gera o JAR em target/quarkus-app/
```

No Windows, use '.\mvnw.cmd' no lugar de './mvnw'.

**Requer JDK 21.** Documentação da API em http://localhost:8080/q/swagger-ui
