# SysmoCrud — Frontend

Interface web em Angular 21 + Bootstrap 5.

Consulte o [README principal](../README.md) para pré-requisitos e instruções completas.

## Comandos

```bash
npm install               # instala as dependências
npm start                 # desenvolvimento (porta 4200)
npm test                  # testes
```


Requer o backend rodando em http://localhost:8080.
